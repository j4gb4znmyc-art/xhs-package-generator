# 得物种草内容生成器｜10组差异化图文工作流

这是一个可本地运行、也可部署到 Streamlit Cloud 的得物种草内容工作流生成器。

工具不直接生成图片，也不需要 OpenAI API Key。用户上传产品资料后，单次生成 1 组完整方案；点击“生成下一组”可为同一产品连续生成最多 10 组不同方向的内容。

## 输入

- 产品图片
- 产品名称、品牌、品类、形态、规格（均可选，建议尽量填写）
- 产品卖点
- 检测报告 PDF/JPG/PNG
- 经人工确认可引用的报告或包装支持点
- 补充要求

检测报告文件不会被自动解释成确定功效。只有用户填写到“检测报告/包装明确支持点”的内容，才会进入文章或提示词。

## 单组输出

- 产品分析
- 独立内容主题与方向
- 3 个标题
- 1 篇 200–500 字得物种草文章
- 6–10 个标签
- 根据资料丰富度自动生成 5–8 张独立图片提示词
- Markdown 一键复制与下载

## 10 组避重机制

项目使用 `previous_groups.json` 按产品记录：

- 已生成主题和内容方向
- 已使用场景
- 已使用人物类型
- 已使用动作
- 已使用镜头
- 已表达卖点
- 已使用文章角度

点击“生成下一组”时会读取历史并自动避重，最多生成 10 组。每张提示词均要求竖版 4:5、单张独立出图、真实人物与真实家庭空间，并保护上传产品的包装、Logo、品牌名、颜色、标签和规格。

## 本地运行

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

打开 `http://localhost:8501`。

## 部署

Streamlit Cloud 使用：

```text
Branch: main
Main file path: app.py
```

推送到原 GitHub 仓库后，原公网网址会自动更新。
